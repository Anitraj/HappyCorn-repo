# HappyCorn 3D

Premium 3D HappyCorn popcorn website, migrated from the Floot project for Vercel deployment.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run typecheck
npm run build
```

The four approved 3D pouch models and the current hero banner are served from the existing public HappyCorn Floot asset host.
